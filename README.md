# Customer Insights Hub

Built an App using the 4 data i uploaded, that receives the phone number of a customer and returns the data of any selected month/months:

PL limit in each Month (Each Last 3 Month and Current Month)

Last 3 months Loan usage (Each Last 3 Month and Current Month)

Average repayment days for last 3 months (Each Last 3 Month and Current Month)

PL balance(Current Month)

Collection active days for each month (Each Last 3 Month and Current Month)

Collection amount for each month (Each Last 3 Month and Current Month)

POS number of days active in each month (Each Last 3 Month and Current Month)

And the App should be able to do the same when i update the data daily.
